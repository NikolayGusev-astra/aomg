# ADR-0001: AOMG — архитектурное решение

Статус: accepted, 2026-09-29

## Контекст

Локальные MCP-серверы в MCP-клиентах страдают от четырёх болезней: жизнь привязана к
агент-процессу, смерть видна только при обращении, файл-локи мешают обновлению
агента, нет управления для не-инженера. Часть MCP — серверные (SaaS), часть
локальная (stdio exe/npm), часть требует VPN или корпоративной сети.

## Решение

Единственный процесс AOMG в трее Windows: супервизор + HTTP-гейтвей + GUI.

- Гейтвей: один порт 127.0.0.1:9300, каждый MCP по пути /<имя>/mcp (Streamable
  HTTP). Локальные stdio-MCP спавнятся детьми и проксируются, серверные —
  reverse-proxy с per-group прокси.
- Супервизор: рестарт умерших детей, пин версий пакетов при установке.
- Watchdog: раз в 30 сек полный initialize + tools/list через тот же egress,
  каким ходит агент. TCP-connect не считается проверкой. Различает «сервер
  умер» (красная) и «канал недоступен» (жёлтая, VPN/сеть лежит).
- Конфиг-синк: AOMG сам прописывает в конфиг MCP-клиента записи
  mcp_servers.<имя>.url = http://127.0.0.1:9300/<имя>/mcp. Агент не знает
  источник: локальный exe или SaaS — одинаково.
- Группы egress: direct / socks5 VPN / corp proxy, per-connection маршрутизация
  внутри гейтвея, без маршрутов Windows и админ-прав. stdio-детям прокси через
  env (HTTPS_PROXY/ALL_PROXY). NO_PROXY=127.0.0.1 зашит.
- Каталог: официальный реестр registry.modelcontextprotocol.io (проверен
  живьём). Рубрики — локальный словарь. Форма ключей строится из
  remotes[].headers (isSecret). Локальные пакеты пинятся по версии.

## Альтернативы, отвергнутые

- Caddy/nginx + mcp-proxy контейнеры: нет watchdog-семантики, нет GUI, нет
  групп egress, Docker Desktop лишняя зависимость для жены.
- IBM ContextForge: тяжёлый сервис с БД и CVE-историей; избыточен для одного
  хозяина, ориентирован на команду.
- mcpd: нет агрегации в один HTTP-порт и нет GUI-установки из каталога.

## Следствия

- Конфиг клиента вечный: url не меняются никогда, апдейт агента не трогает MCP.
- Файл-локи исчезают: агент не родитель MCP-процессов.
- Единственный трайблшутинг жены: цвет иконки + «Перезапустить всё».
- AOMG сам становится SPOF: если процесс умер, агенты без MCP. Смягчение:
  автозапуск, watchdog самого себя не нужен — crash = перезапуск через
  планировщик; алерт в TG при падении.
